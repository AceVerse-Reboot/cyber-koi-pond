# Contributing

Ideas, bug reports and improvements are welcome. Useful areas include more accessible palettes, smaller GIFs, new pond themes and clearer setup instructions.

For a code contribution:

1. Describe the problem or intended visual change.
2. Install `requirements.txt` and run `python -m unittest discover -s tests -v`.
3. Render a local preview with a transparent git-koi GIF and inspect the complete animation.
4. Include a screenshot or GIF when changing the appearance.

Keep upstream attribution intact. Avoid describing decorative AI or security motifs as operational ML or threat detection. Do not commit tokens, credentials or private account data.

Contributions are provided under the project's MIT licence.
